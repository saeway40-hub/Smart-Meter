Load a model from Google Colab

  1. On the History page, download Daily CSV (for Colab) (optional — the notebook can also train on a public dataset).
  2. Open Nehale_Usage_Model.ipynb in Google Colab and run all cells.
  3. The last cell downloads model.json.
  4. Upload it here. The dashboard starts using it immediately.
